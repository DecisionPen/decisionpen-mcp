# Claude Desktop + DecisionPen MCP

Use Claude when you need deep research over DecisionPen’s Context of Record before an important decision. After the plane holds entities and evidence — from a CMDB seed, document discovery, or both — Claude can interrogate landscape, dependencies, standards, and prior decisions without rebuilding the estate in the chat window. Connecting Claude is a natural part of a DecisionPen trial.

Full setup (Edge tokens, install, config): **[CONNECT.md](../CONNECT.md)**.

Hosted remote option: `https://mcp.decisionpen.com/mcp` with `Authorization: Bearer dp_edge_…`.

# Cursor + DecisionPen MCP

Use Cursor when agentic delivery must follow what the enterprise has already approved. DecisionPen holds reference architectures, design patterns, security standards, compliance expectations, and privacy constraints. Cursor can query that pack while designing and implementing, then publish ADRs and design notes back so institutional memory stays current for the next programme. Humans still Confirm what joins the trusted map.
